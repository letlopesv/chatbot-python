# 7DaysOfCode – Chatbot com LangChain e Chainlit

Projeto desenvolvido durante o desafio **#7DaysOfCode** da Alura, com foco em aprendizado prático de configuração de ambiente, Ngrok e ferramentas para construção de chatbots com IA.

## 🛠️ Tecnologias utilizadas
- Python
- Google Colab
- LangChain
- Chainlit
- Pyngrok
- Optimum

## 📌 Dia 1 – Configuração do ambiente
- Instalação das bibliotecas necessárias
- Validação do ambiente
- Registro de limitações do AutoGPTQ em ambientes sem GPU

## 📌 Dia 2 – Configuração do Ngrok
- Instalação do Pyngrok
- Autenticação da conta
- Criação de túnel público para exposição de serviços locais
